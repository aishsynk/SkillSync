Steps to access API

1. Get Access Token & Device Token with help of username, password & role.
2. Use above access token & device token to access next API

-------------------------------------------------------
username : <see SKILLEDGE_RMS_*_USER>
password : <set SKILLEDGE_RMS_*_PASS secret>
role     : Get Latest Version Of Courses

API Base URL : https://api.koenig-solutions.com

--------------------------------------------------------

Step-1 : Getting access token

URL : API Base URL + api/Kites/Operator/GetToken

json request : 

{
  "userName": "<username>",
  "userPassword": "<redacted>",
  "userRole": "<role>"
}

json response : 

{
  "statuscode": 200,
  "message": "OK",
  "content": {
    "accessToken": "<access token>",
    "deviceToken": "<device token>",
    "Username": "<username>",
    "Role": "<role>"
  }
}

----------------------------------------------

Example Request for Get Token API:

{
  "userName": "AISHWAR_GetLatestVersio",
  "userPassword": "<redacted>",
  "userRole": "Get Latest Version Of Courses"
}
