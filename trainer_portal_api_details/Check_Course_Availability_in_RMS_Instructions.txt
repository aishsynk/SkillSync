Steps to access API

1. Get Access Token & Device Token with help of username, password & role.
2. Use above access token & device token to access next API

-------------------------------------------------------
username : <see SKILLEDGE_RMS_*_USER>
password : <set SKILLEDGE_RMS_*_PASS secret>
role     : Check Course Availability in RMS

API Base URL : https://api.koenig-solutions.com

--------------------------------------------------------

Step-1 : Getting access token

URL : API Base URL + api/Kites/Operator/GetToken

json request : 

{
  "userName": "<username>",
  "userPassword": "<redacted>",
  "userRole": "<role>"
}

json response : 

{
  "statuscode": 200,
  "message": "OK",
  "content": {
    "accessToken": "<access token>",
    "deviceToken": "<device token>",
    "Username": "<username>",
    "Role": "<role>"
  }
}

----------------------------------------------

Example Request for Get Token API:

{
  "userName": "AISHWAR_CheckCourseAvai",
  "userPassword": "<redacted>",
  "userRole": "Check Course Availability in RMS"
}

-----------------------------------------------
-----------------------------------------------

Step-2 : Access Check Course Availability in RMS

URL : Base API + api/Kites/Operator/common?apikey={api_key}&accessToken={youraccesstoken}&deviceToken={YourdeviceToken}

json request : 
{
  "CourseName": ""
}

json response :
{
  "statuscode": 200,
  "message": "OK",
  "content": [
  {
    "Course Available in RMS": null,
    "Is Duplicate": null,
    "Is Discontinued": null,
    "Course Status": null
  }
]
}
